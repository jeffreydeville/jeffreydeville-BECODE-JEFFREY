# Exercices HTML, CSS et JavaScript

Ce dépôt contient une série d'exercices destinés à l'apprentissage du développement web avec **HTML**, **CSS** et **JavaScript**. Les exercices couvrent une gamme de concepts fondamentaux en développement web, allant de la structure des pages HTML à la mise en page avec CSS et l'interactivité avec JavaScript.

## Contenu du dépôt

Les exercices sont organisés par catégorie et incluent des problèmes de différents niveaux de difficulté, allant des bases aux concepts plus avancés.

### Catégories

1. **HTML**
   - Structure de base d'une page HTML
   - Utilisation des balises de mise en forme
   - Formulaires HTML
   - Liens et images

2. **CSS**
   - Mise en page avec Flexbox et Grid
   - Styles de base (couleurs, polices, bordures, etc.)
   -* Animation CSS (à revoir)*
   - Responsivité et media queries

3. **JavaScript**
   - Manipulation du DOM
   - Gestion des événements (click, scroll, etc.)
   - Fonctions et boucles
   - Manipulation des tableaux et objets
   - Appels API simples
